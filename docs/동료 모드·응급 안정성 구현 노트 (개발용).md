## 2. 가이드 데이터

```js
{ id:"chest", aud:"both",                         // "self" | "crewmate" | "both"
  q:"Do you have chest pain…?",  qp:"Does {name} have chest pain…?",
  steps:[ {id:"a", type:"do", text:"Stop what you are doing…", sub:"Tell a crewmate…",
           tp:"Have {name} stop, then hold on or strap in.", sp:"Stay with {name}."}, … ] }
```

- 문장을 고르는 곳은 세 함수다. `qText(p, pid)`는 트리아지 질문, `stText(st)`는 단계 문장, `subText(st)`는 보조 문장이다. 동료 모드인데 `qp`/`tp`/`sp`가 없으면 본인용 문장을 쓴다. `{name}`은 환자 이름으로 바뀐다.
- **[차이]** 지침서에는 `audience`, `textSelf`, `textPeer`로 적혀 있지만, 기존 데이터 이름(`q`, `text`, `sub`)에 맞춰 짧은 이름 `aud`, `qp`, `tp`, `sp`를 썼다.
- `panic` 가이드는 목록 맨 끝에 있어서 트리아지에서도 마지막에 묻는다. 흉통이 있으면 `switch:chest`, 연기·CO₂ 경보나 SpO₂ 92% 이하이면 `switch:toxic`로 간다. 숫자 기준이나 타이머는 없다.
- `guideLinks`는 기분 등급이 Act 이상이면 공황 가이드 **버튼만** 보여 준다. 가이드를 자동으로 열지는 않는다.

## 3. 동료 모드 흐름

1. 상단 **👥 크루 관리**에서 지금 앱을 든 사람(`S.me`)을 "나로 지정"으로 고른다. 로스터에는 "(나)"로 표시된다.
   - 같은 창에서 크루원을 **추가**(이름, 역할)하거나 **삭제**할 수 있다. 목록은 localStorage `orbitguide.crew`에 저장된다.
   - 새 크루원의 기준값은 일반 성인 값(심박 62, 혈압 118, SpO₂ 98 등, 시뮬레이션)으로 시작한다.
   - 최소 2명은 남겨야 하고(서로 도와야 하므로), 응급 가이드 진행 중에는 삭제할 수 없다. 삭제는 두 번 눌러야 된다.
   - "기본 크루로 되돌리기"로 Kim, Okafor, Novak, Park으로 돌아간다. 가이드 데모는 항상 기본 크루로 돌고, 끝나면 사용자의 크루로 되돌린다.
   - **[차이]** 처음 구현의 "I am" 드롭다운은 로스터와 중복이라 없앴다(2026-11-14).
2. 다른 크루원이 오늘 Urgent이면 로스터 카드가 깜빡이고 "Needs help"와 **Help {name}** 버튼이 뜬다(`.crew.need`).
   - 이때는 홈 탭에서도 로스터 줄이 보인다(`body.crew-alert`).
   - 동작 줄이기(reduced motion) 설정이면 깜빡이지 않는다.
3. Help를 누르면 `helpCrew(id)`가 실행된다. 환자가 정해진 상태로 SOS 트리아지가 열리고, 질문은 그 크루원 기준으로 바뀐다.
4. 응급 탭에 직접 들어오면 **Who needs help?** 카드가 먼저 나온다. 나를 맨 앞에, 그다음 Urgent인 크루원을 놓는다.
5. 대상이 `crewmate`인 가이드(CPR)는 **선택 화면 없이 바로 시작**한다. 본인으로 시작하면 `R.patient = null`(미확인)이고, 응급 띠에 크루 이름 버튼이 뜬다. 누르면 `identifyPatient(id)`가 환자를 지정하고, 그 전에 잰 값(`R.pendingVals`)을 그 사람 기록에 저장한다. 미확인이면 단계 문장은 본인용(중립) 문장을 쓴다.
   - **[차이]** 지침서는 "Ask a crewmate" 안내 후 처치자를 고르게 했지만, 쓰러진 상황에서 방해가 되어 바꿨다(2026-11-14).
6. 가이드를 시작하면 3D, 상세 패널, 상단 정보가 환자로 바뀐다(`setCrew(patient)`). 응급 띠에는 `Helping: Kim · usual HR … SpO₂ … Temp …`가 표시된다.
7. 측정 단계 값은 `saveMeasure`로 **환자의** 오늘 체크인(`S.checkins[patient][env|day]`)에 합쳐진다. `measuredBy`도 함께 저장되고, 저장 즉시 등급을 다시 계산한다.
8. 응급 로그 머리말은 PATIENT, RESPONDER, MODE, LOCATION, PATIENT USUAL RANGE 순서다. 일반 지구 전송 노트에는 `PATIENT … · PREPARED BY …` 한 줄이 추가된다.

**기분 점수 숨김:** `moodHidden()`은 `S.crew !== S.me`이고 진행 중인 응급이 없을 때 참이다. 이때 상세 패널의 Mood 줄은 등급만 보이고 클릭할 수 없다. 지구 노트에는 "private to patient"로 적힌다.

**동료 측정:** 로스터에서 다른 크루를 고르고 체크인 탭으로 가면 머리말이 `Measuring for Park (by Kim)`이 되고, 저장할 때 `measuredBy`가 남는다.
- **[차이]** 크루 카드에 별도 메뉴는 만들지 않았다. 기존 "크루 선택 → 체크인" 흐름을 그대로 쓴다.

## 4. 응급 안정성

### 4.1 타이머 (`R.timer`)

```js
R.timer = { g, stepId, sec, dueAt, label, due }   // g = 가이드 id
R.status = "active" | "waiting" | "finished"
```

- 600초를 넘는 타이머(감압병 15분, 발열 4시간)를 시작하면 `waiting` 상태가 된다. 이때부터 다른 탭으로 가도 된다.
- `tickSOS`는 1초마다 돈다(`boot`에서 시작). 모든 탭에서 계속 돌고, 단계 화면의 남은 시간과 대기 띠를 갱신한다.
- 마감이 되면 대기 띠가 빨갛게 바뀌고, 로그에 `Timer due`가 남고, 경고음이 울린다. 로스터 환자 카드에는 ⏱가 뜬다.
- 단계를 떠나면(다음 단계로 가거나 되돌리면) 그 단계의 타이머는 지운다. 되돌릴 때는 로그에 `Timer cleared (step undone)`가 남는다.

### 4.2 저장과 이어하기

- 키 `orbitguide.sos.v1`에 `R` 전체와 `env`, `day`를 저장한다. `Set`은 배열로, 날짜는 ISO 문자열로 바꿔 넣는다.
- 저장하는 때는 `log()`가 불릴 때(시작, 단계, 답변, 측정, 되돌리기, 전환, 대기)와 `renderRun()`이 불릴 때다.
- 저장에 실패하면 `R.saveFail`이 켜지고, 응급 띠에 "Log is not being saved — copy it now"와 [Copy log] 버튼이 뜬다.
- 가이드가 끝나거나(`finishGuide`) 종료되면(`exitGuide`) 저장 키를 지운다.
- 부팅할 때 `offerResume()`이 저장된 응급을 찾으면 "Resume emergency in progress?"를 띄운다.
  - **[Resume]:** 같은 단계, 시계, 로그로 이어 간다. 로그에 "Resumed…"가 남는다.
  - **[Copy log and close]:** 로그 창을 열고, 창을 닫으면 종료한다.

### 4.3 되돌리기 (`R.hist`)

- 앞으로 갈 때마다 `{g, id, ans, type, sw?, measured?}`를 하나씩 쌓는다. 가이드를 전환해도 경로를 초기화하지 않는다.
- `back()`은 마지막 항목을 꺼낸다.
  - 가이드가 다르면 전환을 취소한다(`R.chain.pop()`).
  - `R.done`은 남은 경로로 다시 계산한다. 완료 표시의 키는 `가이드:단계` 형식이다.
- 로그는 지우지 않고 `Undone: {단계} → {답}`을 덧붙인다. 되돌린 단계에서 잰 측정값은 기록에 남기고, 로그에 따로 적는다.
- 첫 단계에서는 버튼이 비활성이다. 버튼 이름은 "Undo last step"이다.

- 11개 가이드, "11 guides" 문구가 동적으로 나온다.
- 나 = Novak, Kim collapse일 때 Help Kim이 뜨고, 질문이 "Is Kim not responding…?"으로 바뀌고, CPR이 환자 Kim, 처치자 Novak으로 시작한다.

- 새로고침하면 Resume 안내가 뜨고, 같은 단계, 환자, 처치자로 이어진다.
- CPR을 본인으로 고르면 바로 시작하고(환자 미확인), 응급 띠에서 Okafor를 누르면 로그·기록·3D·응급 기록 머리말이 Okafor로 바뀐다. 새로고침 후 이어 하기에서도 미확인 상태가 유지된다.
- 공황 가이드에서 흉통 Yes를 누르면 chest로 전환되고, 되돌리면 panic 첫 단계로 돌아간다.
- 발열 4시간 타이머로 waiting 상태가 되고, 다른 탭에서도 대기 띠가 보인다. 마감되면 빨간 띠, Timer due 로그, 로스터 ⏱가 나온다.
- 동료 측정값이 환자(Okafor) 기록에만 저장되고 `measuredBy`가 남는다. 응급 로그 머리말이 맞게 나온다.
- 동료 화면에서 Mood는 숨기고 등급만 보인다. 체크인 머리말에 Measuring for가 나온다.
- 콘솔 오류는 오프라인 three.js 로드 실패뿐이다(인터넷이 되면 정상).

## 7. 한국어 (KO 사전)

- `const KO = {...}`를 언어 함수(`T`) 바로 위에 넣었다. 키는 영어 원문, 값은 한국어다. 약 680개 문구.
- `T()`가 사전에서 못 찾으면 `koName()`이 크루 이름을 `{name}`으로 바꿔 다시 찾는다. 동료용 문장("Tap Kim's shoulders…")이 이름이 채워진 채로 들어오기 때문이다.
- **지구로 보내는 노트와 응급 기록 본문은 영어 그대로** 둔다(관제 센터용). 화면의 사건 기록은 한국어로 보인다.
- 출처 제목, 기관 이름, 단위(bpm, mmHg, mSv), 기준 이름(NEWS2, NASA-STD-3001)은 영어로 둔다.
- 새 문구를 추가하면 `KO`에도 넣는다. 빠진 문구는 한국어 모드에서 `window.__miss`에 모이므로 콘솔에서 확인할 수 있다.
- 번역은 AI(Claude)로 만들었고 팀 검토가 필요하다. 특히 의학 표현은 한 번 더 확인할 것.

## 8. 남은 것 (이번 범위 밖)

- 연습 모드와 실제 응급을 구분하지 않는다.
